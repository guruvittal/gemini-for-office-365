Previous: 2-Tier Model
Shared Service Account: All queries share a single SA without end-user identity attribution.
Hardcoded Settings: Fixed project IDs & datastore configs in environment variables.
No SSO: Unauthenticated frontend connection to the proxy.
Integrated: 3-Tier Enterprise Model
Decoupled Security Gateway: auth-proxy inspects Microsoft Entra RS256 JWTs before backend invocation.
Identity Federation: Google STS token exchange (WIF) and Cloud Identity 3-legged OAuth.
Smart Resilience: Backend detects HTTP 403 unowned sessions and automatically recovers.

End-to-End Identity & Token Exchange Flow

Dual-track authentication supporting Workforce Identity Federation (Track 1) and Google Workspace / Cloud Identity (Track 2).

%%{init: {'theme': 'dark', 'themeVariables': { 'darkMode': true, 'background': '#0b1120', 'primaryColor': '#1e293b', 'primaryTextColor': '#f8fafc', 'primaryBorderColor': '#475569', 'lineColor': '#94a3b8' }}}%%
sequenceDiagram
    autonumber
    actor User as Office 365 User
    participant Taskpane as gemini-frontend (Office Host)
    participant AuthProxy as auth-proxy (FastAPI)
    participant STS as Google STS / OAuth
    participant Backend as askgemini-proxy (Express)
    participant GE as Gemini Enterprise (Discovery Engine)

    User->>Taskpane: Opens Word / Excel / PPT Taskpane
    Taskpane->>Taskpane: Office.auth.getAccessToken() (Entra ID SSO)
    Taskpane->>AuthProxy: POST /askGeminiEnterprise (Bearer Entra JWT)
    AuthProxy->>AuthProxy: Verify RS256 Signature via Microsoft JWKS
    
    alt Track 1: Workforce Identity Federation (WIF)
        AuthProxy->>STS: Exchange Entra JWT for Federated Access Token
        STS-->>AuthProxy: Return Short-Lived Google Access Token
    else Track 2: Cloud Identity / Workspace (3-Legged OAuth)
        AuthProxy->>Taskpane: Prompt Google Login Popup (if unauthenticated)
        Taskpane->>STS: 3-Legged OAuth Consent Flow
        STS-->>Taskpane: Return Google User Token
        Taskpane->>AuthProxy: Forward with X-Google-User-Token
    end

    AuthProxy->>Backend: Forward prompt + Google User Token
    Backend->>GE: streamAssist API (v1alpha) with user credential
    GE-->>Backend: Stream Search Results & Citations
    Backend-->>AuthProxy: Stream Response Chunks
    AuthProxy-->>Taskpane: SSE Stream to User Interface
Track 1: WIF (External IdP)
Exchanges Microsoft Entra ID tokens directly with Google STS workforce pool (ca-entra-id-oidc-pool). No Google user accounts needed.
Track 2: Cloud Identity (Google Workspace)
3-legged Google OAuth consent flow enables Gemini Enterprise to search personal Google Drive files and private shared drives securely.
Fallback Guarantee
ALLOW_SERVICE_ACCOUNT_FALLBACK=true ensures unauthenticated demos or general questions continue to function seamlessly.
