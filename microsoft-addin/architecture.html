🎨 Frontend Layer
Hosted on Cloud Run with Nginx. Builds direct in-browser slide presentations via PptxGenJS and adapts smoothly to PowerPoint, Word, and Excel.
🛡️ Security Gateway
auth-proxy verifies Microsoft Entra ID JWT signatures using Microsoft JWKS keys. Operates with REQUIRE_ENTRA_AUTH=false in demo mode.
⚡ Backend Streamer
askgemini-proxy communicates directly with the Discovery Engine streamAssist endpoint. Handles automatic fallback for non-assist queries.

🔐 End-to-End Identity & Token Exchange Flow

Dual-track authentication supporting Workforce Identity Federation (Track 1) and Google Workspace / Cloud Identity (Track 2).

    autonumber
    actor User as Office 365 User
    participant Taskpane as gemini-frontend (Office Host)
    participant AuthProxy as auth-proxy (FastAPI)
    participant STS as Google STS / OAuth
    participant Backend as askgemini-proxy (Express)

    User->>Taskpane: Types prompt ("What is covered in WendysDocs?")
    Taskpane->>Taskpane: Check Office SSO (Office.auth.getAccessToken)
    Taskpane->>AuthProxy: POST /askGeminiEnterprise
    
    alt Sideload / Demo Mode (Current Active)
        AuthProxy->>AuthProxy: Identify user as dev_local_user (Bypass mode)
    else Production Entra ID SSO
        AuthProxy->>AuthProxy: Verify RS256 signature against Microsoft JWKS
    end

    alt Track 1: Workforce Identity Federation (WIF)
        AuthProxy->>STS: Exchange Entra JWT for Federated Access Token
        STS-->>AuthProxy: Return Short-Lived Google Access Token
    else Track 2: Cloud Identity (Service Account Fallback)
        AuthProxy->>Backend: Forward prompt with ADC Service Account Fallback
    end

    Backend->>GE: streamAssist API (v1alpha) on new-ge-app_1780069391112
    GE-->>Backend: Stream grounded document replies + citations
    Backend-->>AuthProxy: Aggregate response & citations
    AuthProxy-->>Taskpane: Return 200 OK JSON payload
    Taskpane-->>User: Render formatted markdown in Taskpane UI
Service Account Fallback
ALLOW_SERVICE_ACCOUNT_FALLBACK=true enables queries to succeed immediately without mandatory login or administrative consent hurdles.
Conversational Resilience
Discovery Engine skips non-assist queries like "hi" with NON_ASSIST_SEEKING_QUERY_IGNORED. The proxy catches this and returns a cordial Gemini greeting.
Document Citations
Retrieved grounding citations include PDF page snippets, exact document names, and URIs for enterprise auditability and zero hallucination.
